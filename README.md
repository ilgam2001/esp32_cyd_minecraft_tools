# ESP32 CYD Minecraft Server Tools created with AI by me

Прошивка для ESP32 CYD 2432S028R с Minecraft-инструментами:

- информация о Java Minecraft-сервере;
- поиск серверов по диапазону портов;
- просмотр скина по никнейму;
- единая Web Config страница;
- сенсорное меню для дисплея 320x240;
- сборка бинарника для Launcher.

## Сборка

Установите PlatformIO и выполните:

```bash
pio run -e cyd_minecraft
```

После сборки Launcher-файл создаётся здесь:

```text
dist/launcher-esp32-2432s028r.bin
```

## Возможности

### Server Info

Подключается к серверу по адресу и порту, получает MOTD, версию, количество игроков, список игроков и ping.

### Server Finder

Сканирует заданный диапазон TCP-портов и показывает найденные Minecraft-серверы. Диапазон портов можно изменить через Web Config.

### Skin Preview

Загружает PNG-текстуру скина по никнейму через публичные Minecraft skin-сервисы. При ошибке сети устройство не должно перезагружаться — на экране отображается статус ошибки.

## Web Config

Откройте пункт `Web Config` на устройстве. В браузере можно настроить:

- адрес и порт сервера;
- начальный и конечный порт Server Finder;
- никнейм для Skin Preview.

Настройки сохраняются во flash-памяти ESP32.

## Подключение

Параметры дисплея и тачскрина находятся в [platformio.ini](platformio.ini). Проект рассчитан на ESP32 CYD с дисплеем ILI9341 320x240.

## Ограничения

- Skin Preview зависит от доступности внешних HTTPS-сервисов.
- Некоторые прокси-серверы Minecraft могут не отвечать на стандартный status handshake.
- Реальная проверка тач-координат и HTTPS должна выполняться на конкретной плате.
